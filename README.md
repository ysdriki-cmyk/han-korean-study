# 韓国語の暗記ノート

韓国語と漢字・意味、または日本語・英語を行き来しながら学ぶWebアプリです。教材と演習モードを選ぶと、そのままカードで練習できます。利用者によるファイルの取り込みや接続設定はありません。

| 教材 | 学習内容 | 同梱カード |
| --- | --- | --- |
| 漢字対応 | 韓国語 ↔ 漢字・意味 | 650枚 |
| 単語暗記 | 韓国語 ↔ 日本語・英語 | 4,559枚 |

単語教材は英語を含む4,337枚と、日本語のみの222枚を収録します。原本の空行や韓国語・意味がそろわない行は出題に含めません。日本語や英語は原本の記述を使い、未記入の訳を自動生成しません。

## 2つの演習モード

| モード | 出題 | 答え方 |
| --- | --- | --- |
| 쓰기（漢→한） | 漢字・意味、または日本語・英語 → 韓国語 | 入力して正解・不正解を自動採点 |
| 읽기（한→漢） | 韓国語 → 漢字・意味、または日本語・英語 | 任意の記入欄で答えを書き、正解を見て自己評価 |

初回は漢字教材の쓰기から始めます。初期設定は「未演習・❌・❌❌❌」「ランダム」「30枚」です。単語教材ではモードの矢印を「訳→한」「한→訳」と表示します。モードは演習・一覧・記録のどの画面からも切り替えられます。

カード一覧で複数のカードを選び、「選んだカードで演習」からその組み合わせを練習することもできます。選んで演習を始める操作では評価を変更しません。

## 漢字の1周目

最初は、元シートのF列「漢字」に説明がある442枚を「必須文字」として出題します。J列の補足説明の有無で判定しません。出題設定の「出題範囲」を「全問題」に切り替えると650枚を選べます。1周目の完了を強制条件にはしていません。

쓰기ではF列の候補を一つだけ提示し、`〔行く다〕` のハングル注記などは解答前に隠します。正解確認で元のF列全文・他の対応漢字を表示します。全問題でF列が空のカードにはI列などの候補を一つ使います。同じ表示ヒントに複数の韓国語が対応する場合は、原本でそのヒントを持つ別解も正解にします。例：`女 → 녀 / 여`、`水 → 물 / 수`。

## 評価と出題設定

回答を確認したら、5つの記号で手ごたえを残します。

| 評価 | 意味 |
| --- | --- |
| ❌❌❌ | 全く思い出せない |
| ❌ | 思い出せない |
| △ | あいまい |
| ○ | できた |
| ◎ | 自信あり |

未演習は「—」です。評価と日時の履歴は、教材・カード・演習モードごとに保存します。읽기と쓰기の評価は独立しており、片方の結果でもう片方を習得済みにはしません。カードの「これまでの評価」から直近8回を確認でき、保存履歴自体は保持します。

쓰기は、入力して「答えを見る・採点」を押すと正誤と正解を表示します。その後の自己評価で自動採点の正誤や試行回数は変わりません。「わからない・正解を見る」は不正解として記録します。읽기の記入欄は任意で、自動採点ではなく正解を見て評価します。

出題設定は選択ボタンで操作します。評価の複数選択、10・20・30・50枚・すべて、ランダム・順番、漢字の1周目・全問題を指定できます。「詳細設定」では過去の誤答期間と最近演習したカードの除外期間を組み合わせます。誤答期間は日時付きの履歴を使い、旧データにない誤答日時は推定しません。

「設定だけ保存」は今の演習を続けたまま次回の設定を保存し、「○枚で始める」は保存して新しい演習を始めます。同じブラウザで開き直しても教材別の設定が残り、「初期設定」で出題条件を初期値に戻せます。

## 演習内の再出題と復習間隔

❌❌❌は通常3問後、❌は通常5問後に同じ演習へ戻します。残りが少ない場合は残りのカードを挟み、同じカードの追加出題は1セットで最大2回です。30枚は最初に選ぶカード数で、再出題分は別に増えます。

○・◎は次の復習日まで間隔を空け、成功を重ねると間隔を広げます。△は翌日が復習日です。

| 評価 | 成功を重ねたときの復習間隔 |
| --- | --- |
| ○ | 1 → 3 → 7 → 14 → 30日 |
| ◎ | 3 → 7 → 14 → 30 → 60日 |

「復習日が来たカードも出す」が初期状態で有効です。初期の評価選択が未演習・❌以下でも、期限が来た日時付きの評価を追加します。読み書きの予定は別々に保存し、自動採点が不正解なら自己評価を◎にしても間隔を延ばしません。

以前の8種類のランクと回答履歴は削除せず保持します。初回表示では、テスト待ちを❌、練習中を△、覚えた・読むテスト済みを○、定着を◎に読み替えます。書くモードは以前の書くテストの記録を使い、該当する記録がなければ未演習とします。以後は新しいモード別評価を優先し、旧ランクを自動で書き換えません。

元教材には意味の近い語や複数の対応漢字があります。自己評価ではカードに記載された答えを確認してください。쓰기はUnicodeの合成と空白の違いを吸収して登録語と照合します。単語教材の主見出しに単語単位の別表記が明示されている場合は、そのいずれかでも正解にします。例えば `완전히, 온전히` は `완전히` または `온전히` で答えられます。文章を自動分割したり、原本の古い複製列 `alternateHan` から別解を増やしたり、同義語を推定したりはしません。

## TOPIK1の使用参考例

解答を開くと、同梱の「フラッシュカード - 【TOPIK1】.csv」から、答えの韓国語をE列で部分一致検索し、使用参考例を「韓国単語・英語・日本語」の3列で表示します。最初の4件を表示し、残りは「ほか○件を見る」から開けます。完全一致の単語を先に並べ、同じ単語でも訳が異なる行は残します。

列の対応はE列＝韓国単語、F列＝英語、G列＝日本語、K列＝韓国語例文、N列＝例文の日本語訳です。例文と訳がある行では、その内容も同じ表の韓国語・日本語欄に表示します。未記入の英語は「—」とし、訳や例文を自動生成・補正しません。

原本をそのまま `dist/data/topik1.csv` に同梱し、有効な825件を読み込みます。利用者によるCSVの取り込みや接続設定は不要です。参考例の取得に失敗しても演習は続けられ、解答画面から参考例だけを再読み込みできます。

## 開発・確認

Node.jsを用意し、このフォルダで実行します。追加のnpmパッケージは不要です。

```sh
npm run dev
```

ターミナルに表示されたローカルURLを開きます。CSVを読み込むため、`index.html` の直接表示ではなくHTTPサーバーを使います。

```sh
npm test
```

教材の解析・学習ロジックと、任意のCloudflare接続APIを検証します。

## 教材の管理者向け設定

漢字教材は `dist/data/cards.csv` に同梱しています。元の「フラッシュカード - 한→漢.csv」の、空見出しや補足列を持つ形式に対応します。新規の漢字教材では次の見出しを推奨します。

```csv
No.,state,Han,漢字,一覧,意味
1,,가,〔行く다〕,家、歌、加,
2,,각,各、覚,角、各、覚、閣、刻、却、脚,各、おのおの
```

| 列 | 扱い |
| --- | --- |
| `No.` / `id` | カードを識別する値。並べ替えや教材更新でも変更・再利用しない |
| `state` | 元教材の状態の記述 |
| `Han` | ハングル。内部ではNFCで正規化 |
| `漢字` | 元シートの漢字・意味・語尾など |
| `一覧` | 対応する漢字の一覧 |
| `意味` | 補足説明。元シート末尾の無名列も補足として読み込む |

元の「漢字」列には日本語の意味や固有語も混在しています。教材の記述をそのまま表示し、漢字語として自動修正しません。ハングルと答えになる内容がそろった行を出題対象にします。教材更新後も同じカードの学習記録を引き継ぐため、既存の `No.` / `id` を維持してください。

単語教材は「フラッシュカード - 単語.csv」から、韓国語、日本語の意味、英語の意味、出典の状態を取り込み、`dist/data/vocabulary.csv` に同梱しています。原本では `English` が英語、`youtube subtitle` が日本語、`moments いろいろhello talk` が主な韓国語の列です。`한글` は古い複製列として保持しますが、入力の別解には自動追加しません。周辺のYouTube URLや分類用の列は主な答えとして扱いません。

原本の `state` は互換用の旧ランクへ読み替え、初回の記号評価の基準にします。例として `卍GO`・`卍行け` は❌、`remember` は意味を答えるモードの○、`書ける`・`read3` は◎の基準になります。単語原本の `remember` チェック列だけで習得済みにはしません。保存済みのモード別評価を優先します。

スプレッドシートを教材の管理元にする場合は、管理者がGoogle Sheetsの対象タブをCSV形式で公開し、`dist/assets/config.js` の教材ごとの接続先を設定して配信します。Googleへの直接取得が制限される場合は、[Cloudflareの読み取りAPI](cloudflare/README.md)を使えます。利用者の画面にはCSVや接続設定を表示しません。

```js
window.APP_CONFIG = {
  defaultDeck: 'kanji',
  decks: {
    vocabulary: { csvUrl: '', fallbackCsvUrl: './data/vocabulary.csv' },
    kanji: { csvUrl: '', fallbackCsvUrl: './data/cards.csv' }
  },
  refreshIntervalMs: 60000,
  fetchTimeoutMs: 10000
};
```

単語教材は `decks.vocabulary.csvUrl`、漢字教材は `decks.kanji.csvUrl` に公開URLを設定します。初回表示は漢字教材で、以後は保存した教材を優先します。`defaultDeck` は互換用の補助設定です。旧形式のトップ階層 `csvUrl` は漢字教材の互換設定としてのみ扱い、新規設定は `decks` を使います。

```text
https://docs.google.com/spreadsheets/d/e/公開ID/pub?gid=0&single=true&output=csv
```

外部接続先が未設定なら同梱教材を使います。教材ごとの接続先を混同しないようにしてください。外部教材の更新間隔と取得時間の上限も `config.js` で管理します。更新時も利用者の学習記録は別に保持します。Googleの公開版への反映には数分かかる場合があるため、定期取得でも編集直後の反映は保証されません。[Google公式の公開設定](https://support.google.com/docs/answer/183965?hl=ja)

## 学習記録の保存

評価と回答履歴は、教材・演習モードごとに分けて、この端末・ブラウザの `localStorage` に保存します。同じ番号のカードが別教材にあっても学習記録を混ぜません。同じブラウザで再び開くと続きから学習できます。別端末への同期、ログイン、学習記録のファイル入出力はありません。ブラウザのサイトデータを削除すると学習記録も削除されます。

現行の保存キーは `han-hanja:learning:v3` です。レコードのカードIDに `kanji:<No>` または `vocabulary:<No>` の名前空間を付けます。新しい評価は各レコードの `assessments.read`・`assessments.write` に保存し、以前の `rank` や回答履歴もそのまま保持します。

教材ごとの演習設定は `han-hanja:preferences:v4` に保存します。`mode`、`ratings`、`scope`、枚数・出題順・復習条件を管理します。v4へ初めて切り替えるときは今回の初期設定を適用し、その後は保存した設定を優先します。学習記録の保存キーは変えず、以前の評価・回答履歴を保持します。

教材のクラウド取得と、学習記録のクラウド保存は別の仕組みです。現行版に端末間の学習記録同期やスプレッドシートへの書き戻しはありません。将来は利用者認証、カードIDをキーにしたD1などの保存先、Sheets APIによる更新を追加できます。

## 構成

```text
dist/
  index.html          画面
  assets/
    app.js            教材・2モード・出題設定・カード一覧の操作
    decks.js          教材の切り替え・カードIDと保存記録の分離
    core.js           漢字教材のCSV解析・正規化
    vocabulary.js     単語教材の解析・正規化
    learning.js       旧ランクと保存記録の互換処理
    assessment.js     モード別評価・履歴・期間の絞り込み
    practice.js       演習設定の保存・移行と出題対象の選択
    kanji.js          F列の必須文字・一つのヒント・対応する別解
    review.js         同一演習の再出題と復習日の計算
    config.js         管理者向けの教材接続設定
    practice.css      演習画面の表示
    supporting.css    一覧・記録の表示
    ratings.css       記号評価と出題設定の表示
    review.css        復習・記入欄の表示
  data/cards.csv      漢字・意味の教材
  data/vocabulary.csv 日本語・英語の単語教材
functions/api/cards.js  任意のCloudflare Pages読み取りAPI
tests/                データ処理・学習ロジック・APIの検証
```

`DrM-OSCE-ver2-main` の「教材読込・整形」「API」「セッション・画面」を分ける構成を参考に、静的ファイルとブラウザ内保存を中心にしています。教材の取得先を差し替えられるため、学習画面を変えずに将来の接続を追加できます。参考プロジェクト自体は変更していません。

静的ホスティングでは `dist/` を配信します。Cloudflare固有の連携設定は [cloudflare/README.md](cloudflare/README.md) を参照してください。
