# 한 → 漢 — 韓国語と漢字の暗記ノート

ハングルと漢字・意味を行き来しながら、学習対象の選択、暗記、読むテスト、書くテストまでWebサイト内で進める学習アプリです。利用者がファイルを取り込んだり、接続先を設定したりする操作はありません。

## 学習の流れ

1. 単語一覧から学習対象を選びます。検索やランクによる絞り込みができます。
2. ハングルまたは漢字・意味を見て思い出し、答えを確認して自己評価します。
3. 想起の練習で正解を重ねたら、読むテスト・韓国語を入力する書くテストへ進みます。

| 内部ランク | 学習上の位置づけ |
| --- | --- |
| `required` | 優先して学びたい単語 |
| `next` | 次に取り組む単語 |
| `later` | あとで取り組む単語 |
| `manji` | 選んで暗記に取り組んでいる単語 |
| `fair` | 想起の練習で1回正解 |
| `mastered` | 想起の練習で再び正解 |
| `read` | 読むテストまで進めた単語 |
| `read2` | 書くテストまで進めた単語 |

カードには共通のランクを一つ持たせ、出題方向ごとの回答履歴は別に記録します。読むテストはハングルから漢字・意味を思い出して自己評価します。書くテストは提示された漢字・意味を見て韓国語を入力し、登録されたハングルとの一致を判定します。

元教材には意味の近い語や複数の対応漢字があります。自己評価ではカードに記載された答えを確認してください。入力判定は登録語との照合であり、同義語や文脈上の別解を推定する採点ではありません。

## 開発・確認

Node.jsを用意し、このフォルダで実行します。追加のnpmパッケージは不要です。

```sh
npm run dev
```

ターミナルに表示されたローカルURLを開きます。CSVを読み込むため、`index.html` の直接表示ではなくHTTPサーバーを使います。

```sh
npm test
```

教材の解析・学習ロジックと、任意のCloudflare接続APIを検証します。

## 教材の管理者向け設定

教材は `dist/data/cards.csv` に同梱しています。元の「フラッシュカード - 한→漢.csv」の、空見出しや補足列を持つ形式に対応します。新規の教材では次の見出しを推奨します。

```csv
No.,state,Han,漢字,一覧,意味
1,,가,〔行く다〕,家、歌、加,
2,,각,各、覚,角、各、覚、閣、刻、却、脚,各、おのおの
```

| 列 | 扱い |
| --- | --- |
| `No.` / `id` | カードを識別する値。並べ替えや教材更新でも変更・再利用しない |
| `state` | 元教材の状態の記述 |
| `Han` | ハングル。内部ではNFCで正規化 |
| `漢字` | 元シートの漢字・意味・語尾など |
| `一覧` | 対応する漢字の一覧 |
| `意味` | 補足説明。元シート末尾の無名列も補足として読み込む |

元の「漢字」列には日本語の意味や固有語も混在しています。教材の記述をそのまま表示し、漢字語として自動修正しません。ハングルと答えになる内容がそろった行を出題対象にします。教材更新後も同じカードの学習記録を引き継ぐため、既存の `No.` / `id` を維持してください。

スプレッドシートを教材の管理元にする場合は、管理者がGoogle Sheetsの対象タブをCSV形式で公開し、`dist/assets/config.js` の `window.APP_CONFIG.csvUrl` に公開URLを設定して配信します。Googleへの直接取得が制限される場合は、[Cloudflareの読み取りAPI](cloudflare/README.md)を使い、管理者が `csvUrl` を `/api/cards` に設定します。利用者の画面にはCSVや接続設定を表示しません。

```text
https://docs.google.com/spreadsheets/d/e/公開ID/pub?gid=0&single=true&output=csv
```

`csvUrl` が空なら同梱教材を使います。外部教材の更新間隔と取得時間の上限も `config.js` で管理します。更新時も利用者の学習記録は別に保持します。Googleの公開版への反映には数分かかる場合があるため、定期取得でも編集直後の反映は保証されません。[Google公式の公開設定](https://support.google.com/docs/answer/183965?hl=ja)

## 学習記録の保存

ランクと学習記録は、この端末・ブラウザの `localStorage` に保存します。同じブラウザで再び開くと続きから学習できます。別端末への同期、ログイン、学習記録のファイル入出力はありません。ブラウザのサイトデータを削除すると学習記録も削除されます。

教材のクラウド取得と、学習記録のクラウド保存は別の仕組みです。現行版に端末間の学習記録同期やスプレッドシートへの書き戻しはありません。将来は利用者認証、カードIDをキーにしたD1などの保存先、Sheets APIによる更新を追加できます。

## 構成

```text
dist/
  index.html          画面
  assets/
    app.js            学習対象・暗記・テストの操作
    core.js           CSV解析・教材の正規化・学習ロジック
    config.js         管理者向けの教材接続設定
    styles.css        表示
  data/cards.csv      同梱教材
functions/api/cards.js  任意のCloudflare Pages読み取りAPI
tests/                データ処理・学習ロジック・APIの検証
```

`DrM-OSCE-ver2-main` の「教材読込・整形」「API」「セッション・画面」を分ける構成を参考に、静的ファイルとブラウザ内保存を中心にしています。教材の取得先を差し替えられるため、学習画面を変えずに将来の接続を追加できます。参考プロジェクト自体は変更していません。

静的ホスティングでは `dist/` を配信します。Cloudflare固有の連携設定は [cloudflare/README.md](cloudflare/README.md) を参照してください。
