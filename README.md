# 한と漢 — 開発メモ

韓国語と漢字・意味、または日本語・英語を学ぶ静的Webアプリ。画面は演習と短い選択肢を中心にし、詳しい仕様はこのREADMEで管理する。

## 教材

| 教材 | 件数 | 主な列・扱い |
| --- | --- | --- |
| 한漢 | 650 | `data/cards.csv`。E＝韓国語、F＝説明、I＝漢字候補、J＝補足 |
| 単語 | 4,559 | `data/vocabulary.csv`。主韓国語＝`moments いろいろhello talk`、日本語＝`youtube subtitle`、英語＝`English` |
| TOPIK1参考例 | 825 | `data/topik1.csv`。E＝韓国単語、F＝英語、G＝日本語、K＝韓国語例文、N＝例文訳 |

- 漢字の初期範囲はF列に説明のある442枚。「全問題」で650枚に変更でき、完了による強制ロックはない。
- 쓰기の漢字問題はF列の候補を一つだけ提示。韓国語の語尾注記は隠し、解答後に全文と他の漢字を表示する。Fが空ならI・Jを使う。
- 同じ表示ヒントに対応する韓国語は別解として認める（例：女→녀／여）。元データは書き換えない。
- 単語は韓国語と訳がそろった行を採用。4,337枚に英語があり、222枚は日本語のみ。古い複製列`한글`は別解として自動採用しない。
- No.／idは固定し、再利用しない。内部IDは`kanji:<No>`／`vocabulary:<No>`。IDなしの行は内容から生成する。

## 学習方向・演習の種類

| 軸 | 値 | 動作 |
| --- | --- | --- |
| 学習方向 `mode` | `write`＝쓰기 | 漢字・意味／日本語・英語から韓国語を書く。自動採点 |
| 学習方向 `mode` | `read`＝읽기 | 韓国語から意味を答える。任意記入＋自己評価 |
| 演習種類 `sessionType` | `practice`＝通常演習 | 条件に合うカードから、未演習・少回数を優先 |
| 演習種類 `sessionType` | `review`＝復習 | 指定期間の履歴を、待ち時間中でも出題 |

単語教材の表記は쓰기（単語→단어）／읽기（단어→単語）。評価・回数・復習日は教材×学習方向の4通りで独立する。

## 出題の選定

通常演習の自動出題は次の順序。

1. 教材・学習方向・漢字の範囲・評価・期間条件で対象を絞る。
2. 有効なら、復習日が来た△・○・◎も対象に加える。
3. 復習日前のカードを除く。誤答から48時間の制限もここで適用する。
4. 記録上の演習回数を **0回→1回→2回…** の順に並べる。同数内だけランダム／教材順にする。
5. その先頭から指定枚数を取る。初期値は30枚・ランダム・未回答と❌以下。

**枚数を選ぶ前に回数で優先する。** 未演習が30枚以上あれば未演習だけを出し、2枚だけならその2枚から出す。演習回数の多いカードへの重み付けはしない。「次のセット」も最新の回数で選び直す。未演習を範囲・評価で外した場合は、その指定を守る。

回数＝モード別`assessments.*.attempts`（履歴件数で補完）＋旧形式の同方向の回答回数＋読み書きの試行回数。元シートの状態から回数を推測しない。쓰기で空欄の答えを見た場合も1回だが、正解・誤答には加算しない。「前へ」や採点後の自己評価変更では重複加算しない。

復習は初期値が直近7日。24時間・7日・30日・履歴すべてを選べる。評価は全種類を対象にし、通常演習の評価・誤答期間・最近の除外条件は使わない。教材範囲・枚数・同数時の順番は共通。日付のない旧ランクだけでは対象にせず、未演習も加えない。対象内では復習も回数の少ない順。

一覧で明示的に選んだカードは、その組み合わせを回数順にする。通常演習の誤答48時間制限は守る。復習では指定期間に履歴があるカードだけを選ぶ。どちらも同じセットへの誤答の自動再挿入は行わない。

## 採点と復習日

| 評価ID | 表示 | 通常演習までの間隔 |
| --- | --- | --- |
| `hard`／`again` | ❌❌❌ 全然／❌ もう一度 | 最低48時間 |
| `unsure` | △ あいまい | 1日 |
| `good` | ○ できた | 1→3→7→14→30日 |
| `solid` | ◎ 完璧 | 3→7→14→30→60日 |
| `unseen` | ー 未回答 | 待ち時間なし。ただし直近の誤答48時間は守る |

- 쓰기の正解は直ちに○。○から再正解すると◎。◎での正解は◎を維持する。
- Enter／採点ボタンは空欄でも解答を表示し、`correct:null`・未回答にする。誤答は`correct:false`。
- 採点後に自己評価を変えても、客観的な正誤・試行回数は変えない。
- ○・◎は連続成功で間隔が延びる。誤答・△では成功の連続を切る。
- 復習での解答も記録・復習日を更新する。復習で再び誤答したら、通常演習の48時間は新しい誤答時刻から数える。
- 過去の待ち時間0日の誤答にも、日時付きの履歴から最低48時間を適用。日時を推測して履歴に書き足すことはしない。
- ハングルはNFC合成と空白の違いを吸収して照合。主見出しの明示的な単語別表記は認めるが、同義語・活用形・文章の自動分割から別解を作らない。

## 韓国語の読み上げ

- Web Speech APIの`speechSynthesis`を使う。韓国語ボイスのみを選択し、`ko-KR`、速度0.9で再生。外部の専用TTS APIやキーは不要。
- 対象は읽기の韓国語、解答後の韓国語・別解、一覧の表示中の韓国語、TOPIK参考語・韓国語例文。
- 쓰기の解答前や、一覧で韓国語を隠している間は音声ボタンを出さない。自動再生はしない。
- 同じボタンの再クリックで停止。別の語を押したら切り替え、画面・カード・タブを離れると停止。再生操作は学習記録に影響しない。
- 音声一覧の非同期取得、キャンセル、失敗を処理する。韓国語音声がない環境では英語などへ代替せず、その場で短いエラーを表示する。声・品質・利用可否は端末とブラウザに依存する。
- API資料：[音声一覧](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[言語指定](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/lang)、[再生エラー](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/error_event)。

## TOPIK参考例

解答後に、答えの韓国語をE列へNFCの部分一致で検索。先頭・途中・末尾すべてを対象にし、完全一致を先に、他は元の行順に並べる。該当する全件を韓国単語・英語・日本語の3列で表示する。한漢では初期表示を単語と訳・単語の読み上げに絞り、K・Nの例文・例文訳がある単語のエリアを押すと、その直下に全列幅で例文・日本語訳・韓国語例文の読み上げを開閉できる。開閉用のラベル・矢印は追加せず、単語自体をキーボードでも操作できる。音声ボタンは開閉と独立し、開閉は学習記録を変更しない。単語教材ではK・Nに例文があれば併記し、元の単語カードの例文表示も維持する。例文本文や訳は検索対象にせず、活用形も推測しない。同一内容の重複だけをまとめ、異なる語義・例文は残す。

## 保存と教材接続

- 学習記録：`localStorage['han-hanja:learning:v3']`。カードIDごとの`assessments.read/write`に評価・回数・正誤・日時・履歴・復習日を保存。
- 設定：`localStorage['han-hanja:preferences:v4']`。教材ごとに`mode`、`sessionType`、`reviewDays`、評価・範囲・枚数・順番・期間条件を保存。
- 既存v4の新項目なしは通常演習・復習7日として読み込み、既存の選択を保持。旧記録のランクと回答履歴も保持する。
- 別端末との学習記録同期やSheetsへの書き戻しはない。サイトデータを削除すると記録も削除される。
- 同梱CSVを初期教材にする。管理者が公開SheetsのCSV URLを`assets/config.js`の`decks.kanji.csvUrl`／`decks.vocabulary.csvUrl`へ設定すれば、定期取得できる。失敗時は同梱教材を使う。学習記録は教材とは別に保持する。
- Googleの直接取得が制限される場合は[Cloudflareの読み取りAPI](cloudflare/README.md)を使う。利用者にはCSV取り込み・ダウンロード画面を出さない。

## 開発

ビルド不要のES Modules。`dist/`を静的配信する。CSVを取得するためHTTPサーバーで確認する。

```sh
npm run dev
npm test
```

| ファイル | 責務 |
| --- | --- |
| `app.js` | 画面・教材・セッション・保存・入力 |
| `practice.js` | 設定移行、対象選択、回数計算、少回数順のセッション生成 |
| `review.js` | 復習日の計算、通常演習の誤答48時間制限 |
| `assessment.js` | モード別評価・履歴・期間条件 |
| `learning.js` | 旧ランク・旧記録との互換 |
| `decks.js`／`core.js`／`vocabulary.js` | 教材の解析・固定ID・教材の分離 |
| `kanji.js` | F列の必須文字・ヒント・対応する別解 |
| `topik.js`／`topik-view.js` | TOPIK解析・検索・参考例の表示 |
| `speech.js`／`speech-view.js` | 韓国語音声の制御・ボタン表示 |
| `tests/` | 教材保全・選定・採点・復習・音声の検証 |

詳細なルール説明ページは利用者向けには設けず、必要な条件だけを設定画面で選べるようにする。仕様変更時は選定・履歴のテストとこのREADMEを併せて更新する。
