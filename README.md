# 한と漢 — 開発メモ

韓国語と漢字・意味、単語、日本語との例文対応を学ぶ静的Webアプリ。画面は演習と短い選択肢を中心にし、詳しい仕様はこのREADMEで管理する。

## どのファイルを編集・公開するか

このフォルダがアプリ本体とGitリポジトリのルート。画面の入口は [`dist/index.html`](dist/index.html)、動作・見た目は `dist/assets/`、現在の同梱教材は `dist/data/`。ビルド不要なので、`dist/` 内のファイル自体を編集する。

GitHubにはこのフォルダ全体を登録し、Cloudflare Pagesの公開先を `dist` にする。`functions/` は `dist/` の外に置く。兄弟フォルダの `Korea flash card/`、`archive/`、スクリーンショットは現在のアプリの配信には使わない。

最初の接続と運用手順は[GitHub・Cloudflareへの移行](cloudflare/MIGRATION.md)を参照する

## 教材

通常はGoogle Sheetsの公開CSVをCloudflareの読み取り専用APIから取得する。列名・ID・カテゴリの仕様は[教材シートの形式](docs/content-schema.md)にまとめる。

| 教材 | 2026-10-29確認時点 | 接続先 |
| --- | --- | --- |
| 한漢 | 650枚・必須436枚 | `/api/content/kanji` |
| 単語 | 4,564枚 | `/api/content/vocabulary` |
| TOPIK1参考例 | 819件 | 単語の空欄でない`TOPIK1`列から生成 |

- 漢字の初期範囲は`必須`列の指定。「全問題」で650枚に変更でき、強制ロックはない。
- 쓰기の漢字問題は出題ヒント→漢字候補→解説・一覧の順で一つだけ提示し、解答後に全文を表示する。出題ヒント列は空欄でよい。
- 同じ表示ヒントに対応する韓国語は別解として認める（例：女→녀／여）。
- 単語は韓国語と日本語または英語がそろった行を採用。`別解`は追加の正解表記、`類語`は解答後の表示のみ。`有効`列は使用しない。
- IDは固定し、再利用しない。`id`、漢字の`id_one`、単語の`id_word`に対応。内部IDは`kanji:<ID>`／`vocabulary:<ID>`なので教材間の番号重複は問題ない。IDなしの行は内容から生成するが、編集しても履歴を維持するには固定IDを使う。
- 同梱の`dist/data/`は通信失敗時の予備教材（漢字650・単語4,559・参考例825件）。毎回Sheetsに合わせて更新する必要はない。

## ホームとセット演習

URLのハッシュがない場合はホームを開く。한漢／単語と쓰기／읽기を選び、セットの「演習」または「一覧」へ進む。セットごとに6段階の評価分布、○・◎の割合を表示する。評価は既存のカードIDに保存し、重複するセットでも同じカードの進捗を共有する。教材・学習方向の独立性は維持する。

教材はホームの한漢／単語／sentenceから選ぶ。演習中のヘッダーには教材切替を置かず、セット未選択・対象なしの場合も出題設定へ自動誘導せずホームへ戻る。読み書き・復習・詳細条件は選択中の教材内で操作する。

教材カード直下の「演習を開始する」はセットを指定せず、選択中の教材全体を通常演習する。保存済みの方向・評価条件・枚数・順序を使い、初期値は未演習・❌以下優先、復習日が来た△・○・◎を追加、30枚・ランダム。直前の復習モードや特定セットには限定しない。「演習を続ける」は回答中のセッションに戻る。

- 初期セット：漢字は必須文字／全件、単語は全件／TOPIK1／カテゴリ列の各タグ／TOPIK1列の各タグ。
- 選んだセットの会員カードだけを通常演習・復習・一覧・一覧選択・出題設定の対象にする。未演習・少回数優先、誤答48時間、復習日、30枚・ランダムなどのルールは維持する。
- セット条件は別シート `category_enshu` のCSVで管理できる。[8列の形式と入力例](docs/category-sets.md)を参照。未接続の間は教材から自動生成したセットを使う。
- カテゴリCSVは共有された公開URL（gid `297489818`）を `/api/category-sets` から取得する設定済み。任意の環境変数 `CATEGORY_SHEET_CSV_URL` で取得先を上書きできる。約60秒ごとに更新。無効な条件はセット全体を除外し、全問題へ広げない。
- カテゴリCSVが接続されたらシートで定義したセットだけを表示する（全件・必須文字も必要なら定義する）。選択していたセットが消えた場合も、別の問題へ自動的に広げない。ホームから選び直す。
- 選択したセットIDは `han-hanja:study-sets:v1` に保存。カテゴリCSVは `han-hanja:content:v1:category_enshu` に保存し、通信失敗時には直前の正常な定義を維持する。

## 学習方向・演習の種類

| 軸 | 値 | 動作 |
| --- | --- | --- |
| 学習方向 `mode` | `write`＝쓰기 | 漢字・意味／日本語・英語から韓国語を書く。自動採点 |
| 学習方向 `mode` | `read`＝읽기 | 韓国語から意味を答える。任意記入＋自己評価 |
| 演習種類 `sessionType` | `practice`＝通常演習 | 条件に合うカードから、未演習・少回数を優先 |
| 演習種類 `sessionType` | `review`＝復習 | 指定期間の履歴を、待ち時間中でも出題 |

単語教材の表記は쓰기（単語→단어）／읽기（단어→単語）。sentenceは쓰기（日→한）／읽기（한→日）。評価・回数・復習日は教材×学習方向の6通りで独立する。

初期方向は単語・sentenceが읽기、한漢が쓰기。ホーム・演習内のボタンは左から읽기→쓰기で共通。既存v4設定は`modeDefaultsVersion:1`への初回移行時に単語・sentenceの方向だけ읽기に変更し、枚数・評価条件・記録は維持する。以後は手動選択を保存する。

## sentence

- 単語教材の`例文_韓国語`と`例文_日本語`が両方ある行から1枚ずつ生成する。2026-10-30確認時点で765枚。新しいCSV・API・シートは不要で、単語教材の更新・予備教材の読み込みに追従する。
- 内部IDは`sentence:<単語の固定ID>`。同じ例文が別の単語に付いていても、覚える単語が違うため別カードとする。例文がなくなっても過去の記録は保持する。
- 쓰기は日本語例文から韓国語例文を書く。複数行の入力欄を使い、Enterで採点、Shift+Enterで改行。空欄でも答えを表示できる。읽기は韓国語例文から日本語を回答する。例文全体を照合し、文字のNFKC正規化・空白・文末の句読点を吸収する。部分一致、元の単語、単語の別解では正解にしない。
- 解答後だけ、元の韓国語単語・英語・日本語を3列で表示する。全文・単語それぞれを読み上げ可能。sentenceにはTOPIK使用参考例を重ねて表示しない。
- 単語の既存ランクは例文の習得として引き継がない。新規は未回答、30枚・ランダム・未演習優先で、誤答2日／△以上5日からの復習間隔は共通。
- ホームのセットは単語用`category_enshu`の条件を元の単語に適用し、その対象の例文だけを選ぶ。例文0件のセットはsentence側では表示しない。例えば「韓国語=집」の条件は例文全文ではなく元単語の집に一致する。単語側のセット・評価は変更しない。

## 出題の選定

通常演習の自動出題は次の順序。

1. 教材・学習方向・漢字の範囲・評価・期間条件で対象を絞る。
2. 有効なら、復習日が来た△・○・◎も対象に加える。
3. 復習日前のカードを除く。誤答から48時間の制限もここで適用する。
4. 記録上の演習回数を **0回→1回→2回…** の順に並べる。同数内だけランダム／教材順にする。
5. その先頭から指定枚数を取る。初期値は30枚・ランダム・未回答と❌以下。

**枚数を選ぶ前に回数で優先する。** 未演習が30枚以上あれば未演習だけを出し、2枚だけならその2枚から出す。演習回数の多いカードへの重み付けはしない。「次のセット」も最新の回数で選び直す。未演習を範囲・評価で外した場合は、その指定を守る。

回数＝モード別`assessments.*.attempts`（履歴件数で補完）＋旧形式の同方向の回答回数＋読み書きの試行回数。元シートの状態から回数を推測しない。쓰기で空欄の答えを見た場合も1回だが、正解・誤答には加算しない。「前へ」や採点後の自己評価変更では重複加算しない。

復習は初期値が直近7日。24時間・7日・30日・履歴すべてを選べる。評価は全種類を対象にし、通常演習の評価・誤答期間・最近の除外条件は使わない。教材範囲・枚数・同数時の順番は共通。日付のない旧ランクだけでは対象にせず、未演習も加えない。対象内では復習も回数の少ない順。

一覧で明示的に選んだカードは、その組み合わせを回数順にする。通常演習の誤答48時間制限は守る。復習では指定期間に履歴があるカードだけを選ぶ。どちらも同じセットへの誤答の自動再挿入は行わない。

## 採点と復習日

| 評価ID | 表示 | 通常演習までの間隔 |
| --- | --- | --- |
| `hard`／`again` | ❌❌❌ 全然／❌ もう一度 | 最低48時間 |
| `unsure` | △ あいまい | 5日 |
| `good` | ○ できた | 5→7→14→30→60日 |
| `solid` | ◎ 完璧 | 5→14→30→60→90日 |
| `unseen` | ー 未回答 | 待ち時間なし。ただし直近の誤答48時間は守る |

- 쓰기の正解は直ちに○。○から再正解すると◎。◎での正解は◎を維持する。
- Enter／採点ボタンは空欄でも解答を表示し、`correct:null`・未回答にする。誤答は`correct:false`。
- 採点後に自己評価を変えても、客観的な正誤・試行回数は変えない。
- 同じセット内で「前へ」に戻った問題も評価を変更できる。戻った問題では、その回の評価・復習日を直ちに更新して同じ問題に留まり、確認後に「次へ」で進める。履歴を追加せず、元の演習日時・入力・自動採点結果を保持する。セット完了画面から「前へ」に戻る場合も同様。
- 읽기（韓国語→日本語・漢字）は、解答表示時に未入力なら△、入力が教材の訳・明示された別解と一致すれば○、異なれば❌を選択・記録し、そのまま「次へ」で進める。全角・半角、大文字・小文字、空白、文末の句読点、括弧の補足の有無を吸収する。部分一致・推測した同義語や例文・メモは正解候補にしない。
- 읽기の解答表示は1回の演習として保存し、自己評価の変更や「前へ」での閲覧では回数・正誤を重複加算しない。自己評価を選ぶと従来どおり次の問題へ進む。쓰기の自動採点・○から◎への進行は維持する。
- ○・◎は連続成功で間隔が延びる。誤答・△では成功の連続を切る。
- 復習での解答も記録・復習日を更新する。復習で再び誤答したら、通常演習の48時間は新しい誤答時刻から数える。
- 過去の待ち時間0日の誤答にも、日時付きの履歴から最低48時間を適用。日時を推測して履歴に書き足すことはしない。
- 以前保存した△・○・◎の短い復習日は、元の演習日時から最低5日に読み替える。長い予定日は短縮せず、履歴や学習回数は書き換えない。客観的な誤答は自己評価が○・◎でも48時間を優先する。
- 演習カードには復習予定・評価履歴・重複する問題番号／言語ラベルを表示しない。進捗はカード上のバーに集約し、現在の評価バッジは残す。復習予定は通常画面にリンクのない`/admin/storage/`で、このブラウザの最新30件を確認できる。
- ハングルはNFC合成と空白の違いを吸収して照合。主見出しの明示的な単語別表記は認めるが、同義語・活用形・文章の自動分割から別解を作らない。

## 韓国語の読み上げ

- Web Speech APIの`speechSynthesis`を使う。`ko`、`ko-*`（大文字・アンダースコアも正規化）の韓国語ボイスを認識し、`ko-KR`・端末内の音声を優先。`ko-KR`、速度0.9で再生。外部の専用TTS APIやキーは不要。
- 対象は읽기の韓国語、解答後の韓国語・別解、一覧の表示中の韓国語、TOPIK参考語・韓国語例文。
- 쓰기の解答前や、一覧で韓国語を隠している間は音声ボタンを出さない。
- 쓰기では「答えを見る・採点」またはEnterで正解を表示した直後、そのカードの正しい韓国語を自動で読み上げる。未入力・正解・不正解のいずれも対象。表示の再描画や「前へ」で既に解答済みのカードへ戻るだけでは自動再生しない。
- 읽기では、ユーザーの演習開始・新しいセット・「次へ」・「前へ」などの操作で、表示した問題の韓国語を自動で読み上げる。開始操作と画面切替が続く経路では、切替完了後に同期的に再生する。쓰기では答えを先に読まない。ページを開いた直後の非同期初期化や、읽기の解答表示・参考例の読み込み・再描画からは自動再生しない。
- 同じボタンの再クリックで停止。別の語を押したら切り替え、画面・カード・タブを離れると停止。再生操作は学習記録に影響しない。
- 初期化時と`voiceschanged`で音声一覧を更新し、タップ時にも再取得する。一覧が空・取得失敗・韓国語音声が未掲載の場合も、`voice`を指定せず`lang = 'ko-KR'`で再生を試す。一覧に日本語・英語しかなくても、それらを明示選択しない。最終的な声・品質・言語の解決は端末とブラウザに依存する。
- タップの処理内で同期的に`speak()`する。音声一覧を待つ`await`やタイマー経由では再生しない。遅れて届く`voiceschanged`では自動再生・再試行をしない。
- `onstart`・`onend`・`onerror`で再生状態を更新。開始を10秒間確認できなければ停止して`start-timeout`と表示する（音声不存在とは断定しない）。実際の失敗時はエラーコードを既存の通知に表示し、コンソールの`[韓国語音声]`に指定言語・選択した音声・元のエラーを出力する。ログは学習記録へ保存しない。
- API資料：[音声一覧](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[言語指定](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/lang)、[再生エラー](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/error_event)。

Galaxy / Android Chromeでの実機確認（実機では未確認）：

1. 同じサイトURLをChromeで再読み込みし、韓国語の単語のスピーカーをタップする。初回と2回目、単語一覧・演習・解答後の参考例を確認する。
2. 同じボタンの連続タップで停止・再開し、別の単語への連続タップでは最後に選んだ韓国語だけが再生されることを確認する。カード・画面・タブを離れたときの停止も確認する。
3. 失敗する場合は通知に出る`language-unavailable`、`not-allowed`、`start-timeout`などのコードを控える。詳しい調査ではMacのChromeの`chrome://inspect/#devices`からUSB接続したGalaxyのタブを検査し、Consoleの`[韓国語音声]`を確認する。
4. Samsung TTSの韓国語Playが正常なら、まずその設定を維持したままサイト側の実際のコードを調べる。サイトデータ・ストレージは削除しない（このサイトの学習記録が消える）。自動テストは音声一覧の空配列・遅延・未掲載、クリック内の同期呼び出し、キャンセル・エラーを模擬しており、Galaxy実機の音声出力の確認とは区別する。

## TOPIK参考例

解答後に、答えの韓国語を参考例の韓国単語へNFCの部分一致で検索。先頭・途中・末尾すべてを対象にし、完全一致を先に、他は元の行順に並べる。該当する全件を韓国単語・英語・日本語の3列で表示する。한漢では初期表示を単語と訳・単語の読み上げに絞り、韓国語・日本語の例文がある単語のエリアを押すと、その直下に全列幅で例文・日本語訳・韓国語例文の読み上げを開閉できる。開閉用のラベル・矢印は追加せず、単語自体をキーボードでも操作できる。音声ボタンは開閉と独立し、開閉は学習記録を変更しない。単語教材では例文があれば併記し、元の単語カードの例文表示も維持する。例文本文や訳は検索対象にせず、活用形も推測しない。同一内容の重複だけをまとめ、異なる語義・例文は残す。

## 保存と教材接続

- 学習記録：`localStorage['han-hanja:learning:v3']`。カードIDごとの`assessments.read/write`に評価・回数・正誤・日時・履歴・復習日を保存。
- 設定：`localStorage['han-hanja:preferences:v4']`。教材ごとに`mode`、`sessionType`、`reviewDays`、評価・範囲・枚数・順番・期間条件を保存。
- 既存v4の新項目なしは通常演習・復習7日として読み込み、既存の選択を保持。旧記録のランクと回答履歴も保持する。
- 別端末との学習記録同期やSheetsへの書き戻しはない。サイトデータを削除すると記録も削除される。
- 公開Sheetsを初回・約60秒ごと・タブに戻ったときに取得する。Google側の公開反映には数分かかる場合がある。成功した教材は`han-hanja:content:v1:<教材>`に保存し、取得・解析の失敗時は最後の正常版、なければ同梱教材を使う。学習記録は別に保持する。
- 演習中の問題と採点候補はセット開始時の内容を保つ。更新内容は次のセットから使う。教材編集だけならGitHubへのコミット・再デプロイは不要。
- [Cloudflareの読み取りAPI](cloudflare/README.md)は公開済みの2シートだけを中継する。利用者向けのCSV取り込み・ダウンロード画面は設けない。

| `/admin/schema/` | 実際のCSVの列名・セル位置・用途・値の例 |
| `/admin/storage/` | 認証・同期の実装状況、このブラウザの保存件数・サイズ |
| `/admin/guide/` | スプシの編集・公開・反映確認の手順 |

教材更新の失敗や予備教材への切替は、通常画面へ通知せず管理ページで確認する。教材そのものを読めない場合や学習記録を保存できない場合は、演習に必要なエラー表示を残す。

通常画面の取得結果は `han-hanja:diagnostics:v1` に、教材ごとの使用元・確認日時・直近の成功日時・件数・エラーを保存する。CSV本文、入力した答え、認証情報は診断情報に含めない。管理画面での「接続を再確認」は学習記録・教材キャッシュ・通常画面の取得結果を書き換えず、現在のAPIだけを確認する。旧キャッシュの取得時刻は不明として表示する。

このページ自体に管理者認証はない。リンク非表示とnoindexはアクセス制限ではなく、URLを知っている人は閲覧できる。ブラウザ内の記録はその閲覧者自身のものだけが表示される。外部の管理者認証が必要な場合はCloudflare Accessなどを別途設定する。

## 開発

本番は[Cloudflare Pages](https://han-korean-study.pages.dev/)。コードはGitHubの`main`から自動配信し、教材はGoogle Sheetsから実行時に取得する。[教材形式](docs/content-schema.md)と[GitHub・Cloudflareの運用](cloudflare/MIGRATION.md)を参照する。

ビルド不要のES Modules。`dist/`を静的配信する。CSVを取得するためHTTPサーバーで確認する。`npm run dev`は静的配信なので同梱教材を使い、APIを含める場合はCloudflare Pagesのプレビューで確認する。

```sh
npm run dev
npm test
```
