# variationの教材をスプレッドシートで管理する

variationは、一つの基本文に時間・場所・相手などを足したり、否定・未来・丁寧な形に変えたりして練習するsentence内の教材です。**1行を一つの文、同じ`セットID`を一つの練習セット**として管理します。

教材は**専用のvariationシート**で管理します。接続先は[公開CSV（gid `1475350480`）](https://docs.google.com/spreadsheets/d/e/2PACX-1vRh2suLk8kb79htB7NQhVfed8BuWPiZ04oqQCWsShnxmZDwvtoejMTtINRJgRyTmc_ysQIvjfhGSFnL/pub?gid=1475350480&single=true&output=csv)で、アプリは`/api/content/variation`から読み取ります。通常sentence・extra・conversationを管理する既存sentenceシートへ追記する必要はありません。

専用シートの行はvariationとして読み取るため、`ジャンル`の`#variation`は省略できます。ひな形の`#variation #食事`などを残しても構いません。会話の`#conversation`や`ターン`・`話者`は入れないでください。variationの行は通常sentence・extra・conversationの件数やセットには混ざりません。

ホーム上部の「練習を開始する」は、検索・カテゴリに合う**未演習セット**から一つを等確率でランダムに選びます。未演習かどうかは選択中の읽기／쓰기で判定し、全ての文の演習回数が0のセットだけを対象にします。1文でも解答を表示したセットは候補から外れ、評価が未回答でも演習回数があれば演習済みとして扱います。候補が複数ある場合は直前に開始したセットを避けます。候補がない場合は演習済みのセットへ自動的に広げず、対象セットが全て演習済みなら「未演習のセットはありません」と表示して上部ボタンを無効にします。

選ばれたセット内は、原型から派生へ`順番`通りに全ての文を出します。一覧の「練習」では途中・演習済みのセットも指定でき、「演習を続ける」で途中へ戻れます。「同じ文でもう一度」ではそのセットを繰り返します。

## CSVのひな形

- [編集・取り込み用CSV](templates/variation.csv)
- [アプリに同梱する同じCSV](../dist/data/variation.csv)

UTF-8のCSVです。「キンパを食べた」「学校に行った」「映画を見た」の**3セット、各8文、合計24文**を収録しています。見出しは1行目から始まり、説明行・結合セル・数式はありません。

この初回サンプルは、基本文から付け足し・否定・未来・丁寧な形などを試す8文の構成です。今後の教材はこの8種類や順番に固定せず、[原型の表現を保って変える](#原型の表現を保って変える)基準に従って作成します。

| --- | --- | --- | --- |
| var-eat-001 | 1 | 基本文 | 김밥을 먹었어. |
| var-eat-001 | 2 | 時間を足す | 어제 김밥을 먹었어. |
| var-eat-001 | 4 | 否定にする | 김밥을 안 먹었어. |
| var-eat-001 | 6 | 丁寧に話す | 김밥을 먹었어요. |

## 列の意味

アプリは見出し名で読み取るため、列を並べ替えても使えます。**今後作成・追加するCSVは、ユーザーが指定した次の列順にそろえます。** 既存の管理列と空列を残し、日本語を韓国語より先に置きます。新しい管理列や列順の指定があれば、このひな形も更新します。

| 列 | 見出し |
| --- | --- |
| A | `id_sentence` |
| B | `remember` |
| C | 空列（見出し・値とも空欄） |
| D | `☆方角way☆数字number☆日付date☆季節season★趣味運動hobby` |
| E | `ジャンル` |
| F | `練習指示` |
| G | `例文_日本語` |
| H | `例文_韓国語` |
| I | `別解_韓国語` |
| J | `変化ポイント` |
| K | `セットID` |
| L | `セット名` |
| M | `順番` |
| N | `変形タイプ` |
| O | `話し方` |
| P | `距離感・対象` |
| Q | `使い方メモ` |
| R | `使用韓国語_main` |
| S〜AB | `使用韓国語_1`〜`使用韓国語_10`（番号順） |
| AC | 空列（見出し・値とも空欄） |

`remember`とD列のチェック項目はシート内の管理用です。variationの出題対象やアプリ内の学習記録は、このTRUE/FALSEで切り替えません。既存のCSVを作り直すときはチェック値を維持し、新しく作る行では指定がなければ空欄にします。チェックボックスだけ入力された未使用行や末尾の空列は、教材として数えません。

| 見出し | 必須 | 入れる内容 |
| --- | --- | --- |
| `id_sentence` | 必須 | 各文の固定ID。例：`var_eat_001`。variation内だけでなく既存sentenceシートのIDとも重複させない |
| `ジャンル` | 任意 | `#食事`などの分類。専用シートでは`#variation`を省略できる。ひな形のタグを残してもよい |
| `セットID` | 必須 | 同じ基本文からの変形に共通するID。例：`var-eat-001` |
| `順番` | 必須 | セット内の正の整数。1、2、3…とし、同じセット内で重複させない |
| `例文_韓国語` | 必須 | その行の完成した文。韓→日では問題、日→韓では模範解答 |
| `例文_日本語` | 必須 | 完成した文の日本語訳。日→韓の出題内容と、韓→日の模範解答 |
| `セット名` | 推奨 | 一覧に出す名前。例：`キンパを食べた`。セット内で同じ名前にする |
| `変形タイプ` | 推奨 | 何を練習するか。例：`基本文`、`時間を足す`、`否定にする` |
| `練習指示` | 推奨 | 答えを出すためのお題。例：`元の文に「昨日」を付けてください。` |
| `変化ポイント` | 推奨 | 答え合わせで読む短い説明。例：`어제（昨日）を付け足します。` |
| `別解_韓国語` | 任意 | 追加で正解にする完成文。複数ある場合はセル内改行で1文ずつ指定 |
| `話し方` | 任意 | `タメ口`、`丁寧`など。指示・模範解答と一致させる |
| `距離感・対象` | 任意 | `親しい友達`、`丁寧に話す相手`など |
| `使い方メモ` | 任意 | 場面や使い分けの補足。問題の答えを示す説明はここへ置く |
| `使用韓国語_main` | 任意 | 単語参照に使う辞書形。例：`먹다`、`가다`、`보다`。`드셨어요`なら`드시다` |
| `使用韓国語_1`〜`使用韓国語_10` | 推奨 | その文に出る単語を原形で一語ずつ、文中の登場順に記入。使わない欄は空欄 |

既存の`訳2`・`使用韓国語_1…`・`使用単語ID_1…`などのsentence列も併用できます。必要な単語だけ追記し、使わない列は空欄にします。

### 使用単語を一語ずつ追加する

今後の教材作成では`使用韓国語_1`〜`使用韓国語_10`も埋めます。完成した各文に実際に使われる名詞・動詞・形容詞・副詞・疑問詞などを記載し、助詞や活用語尾は分けません。動詞・形容詞は原形にし、例えば`갔어요`は`가다`、`드셨어요`は`드시다`です。同じ語は一つの行に重複して入れません。

| 例文_韓国語 | 使用韓国語_1 | 使用韓国語_2 | 使用韓国語_3 | 使用韓国語_4 |
| --- | --- | --- | --- | --- |
| 김밥을 먹었어. | 김밥 | 먹다 | | |
| 어제 김밥을 먹었어. | 어제 | 김밥 | 먹다 | |
| 어제 친구랑 김밥을 먹었어요. | 어제 | 친구 | 김밥 | 먹다 |

派生する文に単語を足したら、その行の番号列にも追加します。文から外れた語は番号列から外し、毎回同じ語数にそろえません。`使用韓国語_main`は今回注目する一語の欄として残し、番号列とは別に指定できます。

variationでも解答後に共通の「使用単語」一覧を表示し、単語の意味・他の例文・読み書き別の単語評価を参照できます。単語帳の原形と照合するため、未登録語の意味やIDは推測しません。未登録の語も一覧に残り、日本語は`—`で表示します。同じ表記に複数の語義がある場合は、必要に応じて`使用単語ID_1…`で特定できます。

## IDと順番の決め方

- **文のIDとセットIDは別です。** 文のIDは1行ごとに変え、セットIDは同じ元の文を共有する行でそろえます。
- ID列は文字列として管理します。行番号から生成する数式は使わず、並べ替えや訳の修正でもIDを維持します。削除したIDは再利用しません。
- 学習記録は既存の文章と同じ`sentence:<id_sentence>`へ読み書き別に保存します。`var_`で始めるなど、既存sentenceのIDと重複しない名前にします。
- 画面の順序はCSVの行順より`順番`を優先します。順番は1、2、3…が分かりやすいですが、途中の番号が空いていても構いません。
- **最小の順番の文が基本文**になります。基本文を削除したり、別の文を先頭に移したりすると、練習の基準も変わります。
- 1行は一つのセットに所属します。別の基本文から練習したい場合は、別セットと新しい文IDを作ります。
- セット名などの共通情報は全行に同じ値を入れると編集しやすくなります。空欄は前のスプレッドシート行から自動補完しません。
- 教材の列がすべて空欄の行は、管理用のチェックやメモだけあっても無視します。ID・本文・セット情報・使用単語など教材の列に一部だけ入力され、ID・韓国語・日本語・セットIDが不足していたり、順番が正の整数でなかったり、文ID・同セット内の順番が重複していたりすると、CSV全体を読み込みエラーとして扱います。更新時は最後の正常な教材を維持するので、不完全なセットへ途中で切り替わることはありません。

## 専用のvariationシートへ取り込む手順

1. 共有した公開CSVに対応するvariationタブ（gid `1475350480`）を開きます。シートが空の場合は、ひな形CSVの見出し1行と教材24行を、このタブのA1から取り込みます。
2. CSVをGoogle Sheetsの別タブへ読み込んで内容を確認しても構いません。その場合は、公開対象のvariationタブへ見出しとデータを移します。新しい別タブを作っただけではgidが変わるため、アプリの既存接続先には反映されません。
3. 新しい練習セットを追加するときは、variationタブの末尾へ行を追加します。列は見出しに対応させ、既存の文IDを維持します。通常sentence・extra・conversationのシートは編集不要です。
4. variationタブが引き続き「ウェブに公開」の対象で、同じ公開CSV URLのgid `1475350480`を指していることを確認します。
5. 公開版に行が反映されると、アプリが取得します。Google側の公開反映に加え、サーバーの5分キャッシュとブラウザの約60秒ごとの確認があるため、数分かかる場合があります。練習中の内容は保たれ、新しい内容は次のセットから使われます。

この変更では公開Google Sheetsそのものを編集していません。

## 更新と予備教材

variationの取得・検証・保存はsentenceと別です。正常に読み込んだ専用シートの内容は、ブラウザの`han-hanja:content:v1:variation`へ保存します。公開CSVを取得できない場合やCSVに問題がある場合は、同じ取得先の最後の正常版を維持し、それがなければ同梱24文を使います。空のシートや見出しだけのCSVは、正常な教材として保存しません。

初回にシートが空でも同梱教材で試せます。シートにひな形を取り込み、正常な公開CSVを取得できた後は、シートの教材全体に切り替わります。同梱24文とシートの行は混ぜません。シートを空にしても、取得済みの正常版が自動で消えることはありません。

既存sentenceシートに`#variation`の行があっても、専用variationシートの内容を置き換える取得元にはしません。同梱サンプルを編集するだけではGoogle Sheetsへ書き戻されません。

接続設定は`dist/assets/config.js`の`variation.csvUrl`が`/api/content/variation`、`variation.fallbackCsvUrl`が`./data/variation.csv`です。公開先を変更する場合はCloudflareの任意の環境変数`VARIATION_SHEET_CSV_URL`で上書きできます。通常の教材編集で、この設定や再デプロイを毎回変更する必要はありません。

## 採点と教材の作り方

日→韓は完成した文を照合します。全角・半角、空白、文末の句読点などの表記差は吸収し、同義語や活用形は自動で推測しません。自然な別表現も正解にしたい場合は、**その行の`別解_韓国語`へ完成文を明示**します。単語だけ、変更した語尾だけでは別解になりません。

例として、否定を練習する行では、模範解答を`김밥을 안 먹었어.`、別解を`김밥을 먹지 않았어.`にできます。丁寧に話すお題では、タメ口の答えを別解に混ぜないでください。韓→日は文章の意味を確認し、既存の自己評価も利用できます。

練習指示には、誰が動作をし、誰に話すのかを必要に応じて書きます。`먹었어→먹었어요`は聞き手に丁寧に話す練習、`선생님께서…드셨어요`は先生の動作を敬う練習です。自分が食べた文を、そのまま`드셨어요`へ変えないようにします。

### 原型の表現を保って変える

目的は、**一つの韓国語表現を繰り返し使い、語句や活用を変えて深く覚えること**です。同じ話題で使える別の表現を集めることとは区別します。この基準は2026-11-15以降の新規作成・追加に適用し、既存セットの本文・ID・順番は今回変更しません。

以下は通常の原型重視版の基準です。会話を広げる版を明示して依頼された場合は、[その版の作成方針](#会話を広げる版を依頼された場合)を優先します。

1. **原型の中核表現を決めます。** `몇 살이에요?`なら`몇 살`を使って年齢を尋ねる表現、`어제 회사 동료랑 술을 마셨어요`なら`술을 마시다`が軸です。複雑な原文は`술을 마셨어요.`のように時間や相手を省いた形から始められます。原文そのものもセットに含めます。
2. **中核表現を残して、足す・減らす・活用を変える操作をします。** 時間・相手・場所・量などを加減し、否定・時制・話し方・疑問・条件などを変えます。語順や助詞の変更、元の動詞の尊敬形も使えます。何を維持し、どこを変えたのかを`練習指示`と`変化ポイント`へ具体的に書きます。
3. **同じ話題であることだけを派生の根拠にしません。** `몇 살이에요?`から`저보다 한 살 많으시네요.`へ移ると、原型の年齢を尋ねる表現を使わない別の主述関係になります。単語や場面が共通するだけの文、原型を使わずに相手が返答する文も、原型の変形としては採用しません。
4. **元の出来事から直接つながる結果は扱えます。** 飲酒なら「飲みすぎて二日酔い」「飲んだ量を後悔する」などです。可能なら`술을 너무 많이 마셔서 오늘 숙취가 있어요.`のように、原型の動作と結果を同じ文に残します。「自分で料理するより外食する」は飲酒表現を使わない別の内容なので、このセットへ入れません。
5. **どの派生も最初の原型から確認します。** 前の派生文だけとの関連で次の文を採用せず、結果からさらに別の話題へ何段も広げません。原型の中核表現を保つ変形か、その出来事の直接の結果かを各行で判断します。

| 原型 | 派生例 | 判断 |
| --- | --- | --- |
| 몇 살이에요? | 몇 살이세요? | 可。`몇 살`を残し、相手を敬う形にする |
| 몇 살이에요? | 그때 몇 살이었어요? | 可。`몇 살`を残し、尋ねる時点を過去にする |
| 몇 살이에요? | 저보다 한 살 많으시네요. | 不可。同じ年齢の話でも、原型の質問表現を使わない |
| 술을 마셨어요. | 어제 회사 동료랑 술을 마셨어요. | 可。飲む表現を保ち、時間と一緒に飲んだ人を足す |
| 술을 마셨어요. | 어제 술을 너무 많이 마셔서 오늘 숙취가 있어요. | 可。飲酒表現を残して、その直接の結果を加える |
| 술을 마셨어요. | 직접 요리하기보다는 밖에 나가서 먹는 편이에요. | 不可。飲酒の原型から離れた別の表現になる |

この範囲の中で、原文ごとに異なる変化を選びます。毎回同じ「時間・人・否定・未来・敬語」の順番や、同じ文数には固定しません。長い文にするだけでなく、短く戻す・量だけを否定する・予定と結果を対比する、といった変化も使えます。

敬語は誰の動作を敬うのか、誰に話すのかを明示します。自分が飲んだことは`마셨어요`や`마셨습니다`、ほかの人の動作を敬うときはその人を主語にして`마시셨어요`などを使います。話す人や動作をする人を変える場合も、原型の中核表現は保ちます。

各行は一つの物語の確定した事実として連結せず、原型を別の条件で言い換える独立した練習にします。飲んだ文から飲まなかった文へ変えるなら、否定する条件がお題から分かるようにします。意味の違いは日本語訳にも反映し、解答の韓国語や説明は解答後の欄へ置きます。教材は各行の完成文を確認して保存し、練習中に自動生成しません。

### 会話を広げる版を依頼された場合

ユーザーが「原型はそこまで意識しなくてよい」「この話題から会話を広げたい」と明示したセットでは、その指定を優先します。上記の原型保持は通常の作成基準であり、こうした依頼で同じ語句や主述関係を毎行に強制しません。

年齢の話ver.2なら、年齢を尋ねることに加えて、同い年と分かった反応・タメ口への誘いと了承・若さや外見を褒める言い方・褒められたときの返し・「もう私はおじさんです」と自分を冗談にする言い方などを収録できます。年齢の会話として自然につながり、各行の練習指示から話し手・相手・条件が分かることを重視します。

この版でも、日本語訳と話し方の一致、自分を不自然に敬わないこと、使用単語を原形で一語ずつ登録することは維持します。既存の原型重視版を書き換えず、セット名にver.2などの区別を付け、別のセットID・文IDを使って追加します。
