# 演習セット用シート category_enshu

教材の行を編集せず、別シート `category_enshu` の条件で演習セットを作る。1行に1条件を書く。同じ `category_id` の行は1セットにまとめられる。カードの学習記録は教材の固定IDに保存されるため、セットを重ねて使っても進捗を共有する。

## 必要な8列

1行目に次の見出しを入れる。列の順序は変えてもよい。

```csv
category_id,カテゴリ名,教材,対象列,条件,値,条件の結合,表示順
```

| 見出し | 入力内容 |
| --- | --- |
| `category_id` | セットの固定ID。半角英数字・`_`・`-`、1〜100文字。同じIDを別教材に使わない |
| `カテゴリ名` | 画面に表示するセット名。1〜80文字 |
| `教材` | `one` = 한漢、`word` = 単語 |
| `対象列` | 下表の教材列名 |
| `条件` | `含む`、`含まない`、`タグ一致`、`等しい`、`印あり`、`空欄`、`空欄でない`、`全件` |
| `値` | 比較する文字列。印あり・空欄・空欄でない・全件では空欄 |
| `条件の結合` | `AND` = 全条件を満たす、`OR` = どれかの条件を満たす |
| `表示順` | 小さい数から表示する。整数・小数を使用可 |

同じセットの各行にカテゴリ名・教材・条件の結合・表示順を繰り返すと確認しやすい。2行目以降はこれらを空欄にすると、同じ `category_id` の最初の行の指定を使う。最初の行の条件の結合が空欄なら `AND`、表示順が空欄なら `0`。`category_id` と各行の対象列・条件・値は省略しない（値が不要な条件を除く）。

教材名は `kanji`・`한漢`・`漢字`、`vocabulary`・`単語` でも指定できる。

## 指定できる対象列

| 教材 | 対象列 |
| --- | --- |
| 한漢 (`one`) | `韓国語`、`出題ヒント`、`漢字候補`、`解説・一覧`（`解説`も可）、`必須` |
| 単語 (`word`) | `韓国語`、`日本語`、`英語`、`カテゴリ`、`TOPIK1` |

`カテゴリ` と `TOPIK1` は別の列として照合する。TOPIK1に付いたタグを、カテゴリ列の条件に流用しない。

## 条件の書き方

| 条件 | 動きと例 |
| --- | --- |
| `含む` | 文字列の部分一致。出題ヒントに `『` を含む、など |
| `含まない` | 指定文字列を含まない行 |
| `タグ一致` | カテゴリ・TOPIK1のタグを1つ照合。`travel` と `#travel` は同じタグ。`travel` は `travel plan` と一致しない |
| `等しい` | セル全体が同じ文字列。必須列だけは `TRUE`・`FALSE`・`1`・`0` を指定 |
| `印あり` | 한漢の必須列がオンの行。対象列は `必須`、値は空欄 |
| `空欄` | 対象列が空欄の行 |
| `空欄でない` | 対象列に内容がある行。TOPIK1全体を選ぶときにも使える |
| `全件` | 教材内の全カード。対象列と値を空欄にし、そのセットは1行だけにする |

比較ではUnicodeをNFCにそろえる。`『`・`』`・`.*` などは入力した文字そのものとして照合し、正規表現として解釈しない。部分一致・完全一致の値の前後のスペースも比較対象になる。タグは `#`・全角 `＃`・セル内改行で区切り、タグ名の途中のスペースは残す。

たとえば `『` または `』` のどちらかを含む出題ヒントは、同じIDで2行作り、条件の結合を `OR` にする。旅行タグと日本語の「する」を両方含む単語は、同じIDで2行作り、結合を `AND` にする。

[入力例CSV](templates/category_enshu.csv)には、全件・必須漢字・引用記号を含むヒント・旅行・必須動詞・旅行の必須動詞・接続詞・TOPIK1・未分類を用意した。旅行はTOPIK1列の `#travel`、必須動詞はカテゴリ列の `#必須動詞` を照合する。タグ名は教材の実データと同じ表記に書き換える。該当タグがないセットや、空欄の出題ヒントを検索する引用記号のセットは0件として表示する。

## エラーと反映

未知の列名・条件、必要な値の空欄、同じID内の教材・カテゴリ名・結合・表示順の食い違いがあれば、そのセット全体を除外する。誤った条件だけを落として対象が増えることはない。1セット20条件、全体100セットまで。

IDを保てば、並べ替え・カテゴリ名の変更でカードの学習記録は変わらない。カテゴリ用CSVの公開先は教材CSVとは別に設定する。接続先が未設定の間は、基本セットと教材列から自動生成したカテゴリを使用できる。

接続後は `category_enshu` に定義したセットだけをホームに表示する。全件・必須文字・TOPIK1全体を入口に残したい場合は、それらもこのシートに行を用意する。
