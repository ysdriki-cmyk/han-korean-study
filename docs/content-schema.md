# 教材スプレッドシートの形式 v3

2026-10-29更新。公開CSVを教材の正とし、한漢と単語の2シートをアプリが列名で読み取る。列順は固定しない。現在の公開シートに合わせ、`有効` による除外は行わず、韓国語と出題内容・訳がそろう全行を教材にする。

## 公開シート

| 教材 | gid | アプリの取得先 |
| --- | --- | --- |
| 単語 | `0` | `/api/content/vocabulary` |
| 한漢 | `29317581` | `/api/content/kanji` |

Google側の接続先は `functions/api/content/[deck].js`。公開済みCSVのためAPIキーは不要。サイト側は60秒ごと、またはタブに戻ったときに更新を確認する。Googleの公開版への反映には数分かかる場合があり、厳密な即時更新ではない。

## ID

- 한漢では `id` または `id_one`、単語では `id` または `id_word` を使える。`id_one(漢字)`、`id_word（単語）` のような注記付きの見出しも認める。
- 実際の保存キーは `kanji:<ID>` と `vocabulary:<ID>`。別の教材で同じ番号を使っても衝突しない。各シートの中では重複させない。
- 既存のIDを維持する。並べ替えや訳・説明の修正で採番し直さず、削除したIDを再利用しない。1行に2つの主IDを用意する必要はない。
- ID列を文字列として扱い、行番号で変わる数式を使わない。IDがない旧CSVには内容由来の互換IDを使うが、新規シートでは固定IDを用意する。

## 한漢

| 見出し | 用途 |
| --- | --- |
| `id` / `id_one` | カードの固定ID |
| `韓国語` | 正解となる文字・読み |
| `出題ヒント` | 任意。漢字・意味から韓国語を書くときの問題。複数ならセル内改行 |
| `漢字候補` | 対応する漢字・意味。出題ヒントが空なら、ここから1項目を出題 |
| `解説・一覧` | 解答後に表示する一覧・説明。ヒントと漢字候補がともに空なら、ここから1項目を出題 |
| `必須` | 1周目の対象。`！`、TRUE、1、チェック記号などを認め、空欄は対象外 |

`解説`、旧 `意味`・`一覧`・`Han` 等の見出しも互換で読める。問題に使う内容からは韓国語の注記を除き、ネタバレを避ける。解答後は全文と他の対応を表示する。必須列がある場合はその指定を優先し、旧CSVだけはF列の説明の有無で必須を判定する。

出題ヒントを別途作成する必要はない。漢字候補か解説・一覧に使える内容があれば出題できる。韓国語またはすべての出題内容が空の行は除外し、警告を解析結果に残す。

## 単語

| 見出し | 用途 |
| --- | --- |
| `id` / `id_word` | カードの固定ID |
| `韓国語` | 主な正解の単語・フレーズ |
| `英語` | 英語訳。日本語と少なくとも一方は必要 |
| `日本語` | 日本語訳 |
| `カテゴリ` | 任意。将来のテーマ別セット用の分類 |
| `例文_韓国語` | 任意。解答後に表示する例文 |
| `例文_日本語` | 任意。例文の日本語訳 |
| `解説` | 任意。解答後の補足 |
| `TOPIK1` | 空欄でない行を使用参考例にも使う。ここに入っているジャンル名も保持 |

日本語・英語から韓国語を書く問題では訳が問題になるため、単語に専用の「出題ヒント」列は不要。`有効` は省略でき、残っていても今は出題の除外条件に使わない。

任意で残せる追加列：

- `別解` / `正解表記`：採点で正解にする韓国語をセル内改行で指定する。未記入なら主見出しだけを正解とする（旧見出し内の明示的な複数表記の互換は維持）。
- `類語`：意味の近い語を解答後に表示するための列。自動的に正解にはしない。別解と混同しない。

## TOPIK1とカテゴリ

`TOPIK1` 列はチェックボックスではなく、現在のシートのように分類名を入れるテキスト列として扱う。空欄は非対象、`#shop`、`#travel`、日本語の分類名など、空欄以外は対象。文字列FALSEも空欄ではないため対象になる。

参考例は単語CSVと同じスナップショットから生成する。韓国語の先頭・途中・末尾で部分一致検索し、完全一致を先にして全件を表示する。同じ内容だけをまとめ、違う語義・例文は残す。한漢では単語・訳をコンパクトに表示して例文を開閉でき、単語では例文も表示する。

`カテゴリ` と `TOPIK1` 内の分類名を、それぞれ元の文字列と正規化した分類として保持する。`#必須動詞 #あいさつ`、全角＃、セル内改行に対応し、前後の空白・重複をそろえる。カテゴリ名内のスペースを勝手に分割せず、空欄を前の行から引き継がない。テーマ別の選択画面・演習ビューは今後設計する。

## 保存と更新

正常に取得・解析できたCSVだけを、学習記録とは別のブラウザ保存領域に保持する。再読込時に通信が失敗したら同じ取得先の保存済みCSV、その次に同梱CSVを使う。不正なCSVやID重複では既存の教材を上書きしない。

演習中の問題・採点に使う対応表はセット開始時の内容を保つ。更新分は一覧・件数・参考例と次のセットに反映する。学習記録は教材ID・方向別のまま保持する。

同梱の旧CSVは障害時や初回オフライン時の予備。Google Sheetsを編集するたびに更新する必要はない。必要な節目でまとめて更新できるが、旧形式・IDの互換テストと一緒に確認する。

教材の使用元・確認日時・CSVのセル対応は管理用の `/admin/` 以下で確認する。通常画面には教材更新失敗や代替元の通知を出さない。`/admin/` 自体に認証はなく、学習画面からのリンクだけを設けていない。
