# 教材スプレッドシートの形式 v4

2026-11-06更新。公開CSVを教材の正とし、한漢・単語・sentenceの3シートをアプリが列名で読み取る。列順は固定しない。`有効` による除外は行わず、韓国語と出題内容・訳がそろう全行を教材にする。

## 公開シート

| 教材 | gid | アプリの取得先 |
| --- | --- | --- |
| 単語 | `0` | `/api/content/vocabulary` |
| 한漢 | `29317581` | `/api/content/kanji` |
| sentence | `64554523` | `/api/content/sentence` |

Google側の接続先は `functions/api/content/[deck].js`。公開済みCSVのためAPIキーは不要。サイト側は60秒ごと、またはタブに戻ったときに更新を確認する。Googleの公開版への反映には数分かかる場合があり、厳密な即時更新ではない。

## ID

- 한漢では `id` または `id_one`、単語では `id` または `id_word` を使える。`id_one(漢字)`、`id_word（単語）` のような注記付きの見出しも認める。
- 実際の保存キーは `kanji:<ID>`・`vocabulary:<ID>`・`sentence:<ID>`。別の教材で同じ番号を使っても衝突しない。各シートの中では重複させない。
- 既存のIDを維持する。並べ替えや訳・説明の修正で採番し直さず、削除したIDを再利用しない。1行に2つの主IDを用意する必要はない。
- ID列を文字列として扱い、行番号で変わる数式を使わない。IDがない旧CSVには内容由来の互換IDを使うが、新規シートでは固定IDを用意する。

## 한漢

| 見出し | 用途 |
| --- | --- |
| `id` / `id_one` | カードの固定ID |
| `韓国語` | 正解となる文字・読み |
| `出題ヒント` | 任意。漢字・意味から韓国語を書くときの問題。複数ならセル内改行 |
| `漢字` / `漢字候補` | 対応する漢字・意味。出題ヒントと別列で保持し、ヒントが空なら、ここから1項目を出題 |
| `解説・一覧` | 解答後に表示する一覧・説明。ヒントと漢字候補がともに空なら、ここから1項目を出題 |
| `必須` | 1周目の対象。`！`、TRUE、1、チェック記号などを認め、空欄は対象外 |

`解説`、旧 `意味`・`一覧`・`Han` 等の見出しも互換で読める。問題に使う内容からは韓国語の注記を除き、ネタバレを避ける。解答後は全文と他の対応を表示する。必須列がある場合はその指定を優先し、旧CSVだけはF列の説明の有無で必須を判定する。

出題ヒントを別途作成する必要はない。漢字候補か解説・一覧に使える内容があれば出題できる。韓国語またはすべての出題内容が空の行は除外し、警告を解析結果に残す。

## 単語

| 見出し | 用途 |
| --- | --- |
| `id` / `id_word` | カードの固定ID |
| `韓国語` | 主な正解の単語・フレーズ |
| `英語` | 英語訳。日本語と少なくとも一方は必要 |
| `日本語` | 日本語訳 |
| `カテゴリ` | 任意。将来のテーマ別セット用の分類 |
| `例文_韓国語` | 任意。解答後に表示する例文 |
| `例文_日本語` | 任意。例文の日本語訳 |
| `解説` | 任意。旧備考の保存用。単語の演習画面では非表示 |
| `TOPIK1` | 空欄でない行を使用参考例にも使う。ここに入っているジャンル名も保持 |

日本語・英語から韓国語を書く問題では訳が問題になるため、単語に専用の「出題ヒント」列は不要。`有効` は省略でき、残っていても今は出題の除外条件に使わない。

任意で残せる追加列：

- `別解` / `正解表記`：採点で正解にする韓国語をセル内改行で指定する。未記入なら主見出しだけを正解とする（旧見出し内の明示的な複数表記の互換は維持）。
- `類語`：意味の近い語を解答後に表示するための列。自動的に正解にはしない。別解と混同しない。

## sentence

| 見出し | 用途 |
| --- | --- |
| `id_sentence` | 必須。文章の固定ID。移行772件は既存の番号を維持する |
| `例文_韓国語` | 必須。文章全体。읽기の問題・쓰기の正解 |
| `例文_日本語` | 必須。文章全体の訳。쓰기の問題・읽기の正解 |
| `訳2` | 任意の補足訳。읽기・쓰기とも答え合わせで表示。空欄なら非表示。出題・自動採点には使わない |
| `使用韓国語_main` | 任意。今回覚えたい単語の辞書形。学習済み単語の例文を優先する判定に使用 |
| `使用韓国語_1`… | 任意。文章内の順番で辞書形を入れる。10列を超えても追加でき、空き番号は飛ばす |
| `文中表記_1`… | 任意。文中の活用形・助詞付き表記。照合・診断用に保持し、使用単語の表は原形を表示する |
| `文中訳_1`… | 任意。文中の訳。例：顔に、書いて。空欄ならhan_wordsの日本語 |
| `使用単語ID_main` / `使用単語ID_1`… | 任意。han_wordsの固定ID。同表記の語義を指定したい場合に使用 |
| `ジャンル` | 任意。`#旅行 #食事` のような分類。`#subtitle`はextra、`#conversation`は会話レッスンとして通常sentenceから分ける |
| `備考` | 任意。編集メモ。演習画面には出さない |

`使用韓国語_main` は番号順とは独立する。メインが文中で3番目なら `_3` に置いてよい。番号欄には辞書形を入れ、活用形は文中表記へ分ける。メインだけでも演習可能で、番号欄が空ならメインを1行表示する。

han_wordsの韓国語・明示された別解との完全一致で原形・英語・日本語を取得する。使用単語IDがあればその行を優先し、韓国語とIDが一致しないときは別の語へ自動置換しない。活用の推測はしない。該当なし・複数候補などは `/admin/sentences/` で確認・CSV出力できる。使用単語の一覧は評価・原形・日本語を表示し、英語と音声と例文は下部パネルに表示する。例文は2件ずつページ送りし、現在の文章と同じ会話レッスンは表示対象に含めず、同じ韓国語・日本語の組をまとめる。

一覧の評価はhan_wordsの固定IDで単語演習の記録を参照する。パネル内で選んだ읽기／쓰기のみ変更し、sentenceの評価・単語の演習回数・履歴・復習日時は変更しない。複数の語義は別行に分け、未登録語には架空の学習記録を作らない。追加のCSV列は不要。

字幕もこのsentenceシートに追記する。`#subtitle`が付いた行は通常の「すべて」・セット・達成率から除外し、sentenceホームのextraからのみ学習する。extra内の一覧・通常演習・復習・タグセットも字幕の範囲に限定する。記録は同じ固定IDで、読み書き別に保存する。予約タグはNFKC正規化後の完全一致で判定するため、`#subtitles`や備考中の文字列ではextraにならない。

移行CSVは旧772件の例文・固定ID・現在のメイン単語だけを引き継ぐ。ほかの使用語は編集者が追加する。新しいsentenceシートが正常に公開されるまでは、同梱の同じ772件を予備として使う。単語シートの例文欄は単語モードの例文表示用として残り、以後sentenceへ自動追加はしない。

### conversation

会話もsentenceシートの1行を1発話として管理する。`#conversation`の完全一致、または正の整数の`ターン`と空欄でない`話者`の両方がある行を会話として識別する。`#subtitle`もある場合はconversationを優先し、通常sentence・extraのセット・件数・達成率には含めない。IDの接頭辞・末尾や備考だけでは分類しない。

| 追加見出し | 用途 |
| --- | --- |
| `セットID` | 同じ会話に共通する固定ID。新しい会話を追加するときに指定する。例：`daily-001` |
| `シチュエーション` | レッスンの表示名。例：`待ち合わせの時間を決める` |
| `単語由来タグ` | 任意。元の単語の分類タグ。`#旅行 #日常`のように複数指定でき、会話の絞り込みに使用。`ジャンル`とは別に保持する |
| `カテゴリ` / `カテゴリ番号` | 任意。カテゴリの名前・管理用番号。レッスンの並びはセットIDの自然順 |
| `ターン` | 会話内の順序。1、2、3…の整数。同じセット内で重複させない |
| `話者` | A、Bなど発話した人。会話レッスンの絞り込みにも使用 |
| `会話の役割` | 任意。話題開始・質問、返答、相槌など。会話レッスンの絞り込みに使用 |
| `話し方` / `距離感・対象` | 任意。丁寧・タメ口、初対面・親しい相手など。会話レッスンの絞り込みに使用 |
| `学習優先度` | 任意。A・B・Cなど編集者の分類。絞り込みに使用し、会話内の順序は変えない |
| `使い方メモ` | 任意。使い方・状況の補足。シチュエーション・レッスン名・カテゴリ・単語由来タグとともに検索対象 |

会話全体を1レッスンとし、`ターン`の昇順で全発話を出題する。ランダム順・枚数上限・評価条件・復習日の制限で会話の途中を抜かない。評価と演習回数は従来の`sentence:<id_sentence>`、읽기／쓰기別のまま保存する。

会話ホームの詳細設定は、実際に入力された値から選択肢を作り、空欄だけの項目は出さない。複数の条件は同じ発話上でAND照合するが、その発話だけに絞らず所属レッスン全体を出題する。`話者=B`と`会話の役割=返答`なら、Bの返答がある会話を選び、Aの発話も残す。入力列はAA以降に限らず、見出し名で読む。

conversationの「レッスンを開始する」は、詳細条件・検索・カテゴリを満たし、選択中の읽기／쓰기で全発話の実際の演習回数が0のレッスンから1件を等確率で選ぶ。途中・演習済みのレッスンは一覧から選べる。2件以上あるときは現在のレッスンを避け、0件なら開始しない。抽選後もターン順を保つ。条件の保存はこのブラウザの`han-hanja:study-sets:v1`内の`conversationFilters`で管理し、Sheetsや学習記録へ書き戻さない。

初回1106発話（158レッスン×7発話）には、提供された会話CSVからレッスンの対応情報を同梱する。対応する固定IDと韓国語本文が一致する場合だけ不足する情報を補い、CSVに入力された空欄でない値を優先する。本文やIDの変更で照合できなくなった行、新規追加行は、CSVに`セットID`・`シチュエーション`・`ターン`・`話者`を指定する。レッスンを特定できない行は消さず単独のレッスンとして残し、無関係な会話へまとめない。同じ会話を編集するときも発話ごとの`id_sentence`を維持する。

## TOPIK1とカテゴリ

`TOPIK1` 列はチェックボックスではなく、現在のシートのように分類名を入れるテキスト列として扱う。空欄は非対象、`#shop`、`#travel`、日本語の分類名など、空欄以外は対象。文字列FALSEも空欄ではないため対象になる。

参考例は単語CSVと同じスナップショットから生成する。韓国語の先頭・途中・末尾で部分一致検索し、完全一致を先にして全件を表示する。同じ内容だけをまとめ、違う語義・例文は残す。한漢では単語・訳をコンパクトに表示して例文を開閉でき、単語では例文も表示する。

`カテゴリ` と `TOPIK1` 内の分類名を、それぞれ元の文字列と正規化した分類として保持する。`#必須動詞 #あいさつ`、全角＃、セル内改行に対応し、前後の空白・重複をそろえる。カテゴリ名内のスペースを勝手に分割せず、空欄を前の行から引き継がない。テーマ別の選択画面・演習ビューは今後設計する。

## 保存と更新

正常に取得・解析できたCSVだけを、学習記録とは別のブラウザ保存領域に保持する。再読込時に通信が失敗したら同じ取得先の保存済みCSV、その次に同梱CSVを使う。不正なCSVやID重複では既存の教材を上書きしない。

演習中の問題・採点に使う対応表はセット開始時の内容を保つ。更新分は一覧・件数・参考例と次のセットに反映する。学習記録は教材ID・方向別のまま保持する。

同梱の旧CSVは障害時や初回オフライン時の予備。Google Sheetsを編集するたびに更新する必要はない。必要な節目でまとめて更新できるが、旧形式・IDの互換テストと一緒に確認する。

教材の使用元・確認日時・CSVのセル対応は管理用の `/admin/` 以下で確認する。通常画面には教材更新失敗や代替元の通知を出さない。`/admin/` 自体に認証はなく、学習画面からのリンクだけを設けていない。
