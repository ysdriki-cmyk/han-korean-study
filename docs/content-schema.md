# 教材スプレッドシートの形式 v2.1

2026-10-29更新。単語とTOPIK1を統合し、1つのGoogleスプレッドシートに以下の2タブを作成する。新しい列名・フラグへのアプリ対応と外部取得はまだ未実装。作成したシートを受け取った後、この仕様に合わせて読込を対応させ、IDの互換性を確認してから接続先を切り替える。

| タブ名（完全一致） | 用途 | 列の範囲 |
| --- | --- | --- |
| `한漢` | 韓国語の文字・読みと漢字・意味の対応問題 | A〜G |
| `単語` | 単語問題と、TOPIK1該当語の使用参考例 | A〜K |

教材として必要なのはこの2タブ。쓰기・읽기・通常演習・復習のために別タブは作らない。TOPIK1は単語タブのチェック列で区別し、独立したタブ・演習コースにはしない。

## 共通ルール

既存シートを原本として残し、配信用の `한漢`、`単語` の2タブを作る。共通教材と各人の学習履歴を分ける。

- 1行目だけを見出しにし、列名の重複・結合セル・途中の見出しや合計をなくす。
- 各タブは以下の列順・見出しを使う。任意項目の列も作り、使わないセルだけ空欄にする。1行を1カードまたは1つの参考語彙にする。
- IDは文字列の固定値。行番号や並べ替えで変わる数式で採番しない。変更・再利用しない。
- `必須`、`TOPIK1`、`有効` はチェックボックス（TRUE / FALSE）。既存の採用カードは最初に `有効=TRUE` にする。
- 必須項目の欠落は確認し、任意項目の空欄はそのままにする。「なし」「-」で埋めない。
- 複数ヒント・採点用の別解はセル内で1項目1行。括弧の意味や韓国語の正しい分かち書きは保つ。
- 自由記述の訳を機械的に分割して別解にしない。採点用の別解は明示的な列で管理する。
- `state`、`remember`、`read`、`read2` 等の個人評価・管理メモは原本に保管する。共通教材の更新で全利用者の評価を上書きしない。
- `韓国語` は表示・採点する文字列そのもの。読み仮名や日本語の説明は混ぜず、説明は `解説` に入れる。単語だけでなく既存のフレーズも1カードとして保持できる。
- セル内改行・カンマを含む内容はGoogle SheetsのCSV出力に任せる。手作業で引用符を付けたり、カンマを削除したりする必要はない。

## 한漢

1行は現在の1カード（韓国語の文字・読み）。漢字候補を1文字ずつ別カードに分解せず、現在の650枚との対応を保つ。

| 列 | 見出し | 入力条件・移し方 |
| --- | --- | --- |
| A | `id` | 必須。元B列 `No.` をそのまま使う |
| B | `韓国語` | 必須。元E列 `Han` |
| C | `出題ヒント` | 元F列から問題に使える漢字・日本語を抽出。韓国語の答えを入れない。複数ならセル内改行。必須文字には入力する |
| D | `漢字候補` | 元I列 `一覧`。Cが空の行は、この列に出題できる漢字・日本語を用意する |
| E | `解説` | 任意。解答後に表示する説明。元F列の全文と元J列の補足を情報を失わず保持 |
| F | `必須` | 必須。移行時の元F列が空でない442枚をTRUEにし、その後は説明の有無と独立して管理 |
| G | `有効` | 必須。出題・表示する行はTRUE |

C・Dの少なくとも一方には出題できる内容を入れる。`必須=TRUE` は初期の1周目の対象、FALSEは「全問題」で扱う。`有効=FALSE` はどちらの範囲でも出題しないが、既存履歴は削除しない。

以下はタブ区切りの見出し。A1に貼り付けて使える。

```text
id	韓国語	出題ヒント	漢字候補	解説	必須	有効
```

解答前に `出題ヒント` の1項目だけ、解答後に残りのヒント・漢字候補・解説を表示する設計。全問題でヒントがない場合のフォールバックも韓国語を隠して提示する。

元F列には複数候補・括弧・韓国語注記がある。自動整形は下書きにし、答えが問題に漏れないか確認する。解説全文は先に保持する。

## 単語

| 列 | 見出し | 入力条件・移し方 |
| --- | --- | --- |
| A | `id` | 必須。元A列 `No`。元H列の古い `No.` と取り違えない |
| B | `韓国語` | 必須。元E列 `moments いろいろhello talk` の主見出し |
| C | `日本語` | 元G列 `youtube subtitle`。日本語・英語のどちらか必須 |
| D | `英語` | 元F列 `English`。日本語があれば空欄でもよい |
| E | `別解` | 任意。採点で認める韓国語だけをセル内改行。旧I列 `한글` は確認せず採用しない |
| F | `例文_韓国語` | 任意。元K列。見出し語と分ける |
| G | `例文_日本語` | 任意。元N列。対応する例文の訳 |
| H | `解説` | 任意。利用者に見せる補足だけ。個人用の管理メモは含めない |
| I | `TOPIK1` | 必須。TOPIK1に該当する行をTRUEにし、使用参考例にも使う。その他はFALSE |
| J | `有効` | 必須。出題・表示する行はTRUE |
| K | `カテゴリ` | 任意。元単語CSVのJ列 `#chat` の分類を保持。テーマ別セットのためのデータとして使う |

韓国語を書く問題ではBを主な正解にし、Eがあればそこに明示された表記も正解にする。C・Dは問題、B・E・F・G・Hは解答後の表示に使う。읽기ではBを問題、C・Dを解答にする。日本語や英語の訳から別解を推測しない。

```text
id	韓国語	日本語	英語	別解	例文_韓国語	例文_日本語	解説	TOPIK1	有効	カテゴリ
```

現在の採用件数は4,559枚。元CSVの5,005行中446行は韓国語・訳の欠落や見出しなどで除外されている。一括削除せず、空行と補完すれば教材になる行を分けて確認する。

同じ韓国語でも語義・用例が異なる可能性があるため、一括で重複削除しない。複数語の見出しを分割する場合は旧IDとの対応・履歴移行を別途決める。

### カテゴリと将来のテーマ別セット

既存のA〜J列の位置を保ち、末尾のK列に `カテゴリ` を追加する。テーマ別の演習ビューや選択方法は後で設計し、今回は分類データの形式だけを用意する。

- 既存の `#必須動詞`、`#あいさつ`、`#形容詞` 等をそのままコピーできる。
- 複数カテゴリは `#形容詞 #あいさつ` のように同じセルに残す。セル内改行による複数指定も使える設計とする。
- 読込側で先頭の `#`・`＃` と前後の空白をそろえ、同じ分類名を重複して登録しない。表示名は「形容詞」「あいさつ」等として扱う。
- `#` のない単一カテゴリ名も認める。スペースを含む分類名を勝手に複数へ分割せず、タグの印または改行で境界を判断する。
- 空欄はカテゴリ未設定。上の行のカテゴリを自動で引き継がず、通常の全体演習の対象には残す。
- `必須動詞` はテーマ名。漢字シートの `必須` チェックや個人の評価・復習日は別の情報として管理する。

## TOPIK1の統合と参考例

単語タブのうち `有効=TRUE` かつ `TOPIK1=TRUE` の行を、使用参考例の検索対象にする。これらの行は通常の単語教材としても使う。`有効=FALSE` の行は演習・参考例のどちらにも出さない。

検索対象はB列の韓国語。先頭・途中・末尾の部分一致で該当全件を表示する。表示列は韓国語・英語・日本語。한漢では単語と訳のみ、単語では例文も表示する。

旧TOPIK1の韓国語はE列、英語はF列、日本語はG列、例文はK列、例文訳はN列から移す。

- 同じ韓国語・語義の既存単語に統合する場合は、その単語のIDを維持して `TOPIK1=TRUE` にする。
- 旧TOPIK1にしかない単語を追加する場合は、単語タブで未使用の固定IDを付ける。旧TOPIK1のNoが既存の単語と同じでも同一項目とは推測しない。
- 語義・例文が異なるものは、韓国語の一致だけでまとめない。必要なら別IDの行として残し、例文を上書きして失わない。
- 統合前の旧TOPIK1は825件。統合後の件数をこの値に無理に合わせず、元の内容が落ちていないか確認する。

## IDと切り替え

既存の内部IDは `kanji:<元No.>` と `vocabulary:<元No>`。新シートには元の値だけを入れ、`kanji:` 等を重ねて入れない。並べ替え・誤字・訳・解説の修正でIDを変えない。別問題への変更、分割・統合は履歴の扱いを個別に決める。

個人評価は将来のDBで `利用者ID × 教材 × カードID × 쓰기/읽기` ごとに保存する。

1. 原本をバックアップし、配信用2タブに機械的に移せる値と固定IDを移す。
2. 未入力・語義の違う重複・複数語の見出し・韓国語を含むヒントを確認する。
3. `有効` と `必須` を入力する。既存の必須442枚を維持する。
4. アプリに新列名、明示的な別解、必須・有効・TOPIK1フラグを実装する。単語データから使用参考例を生成する。
5. ID・件数差・問題のネタバレ・採点・参考例を確認してから接続先を切り替える。

現在は使用参考例を旧TOPIK1の別CSVから列位置で読んでいるため、アプリ対応前に新しいシートへ接続しない。2タブを取得する構成へ変更し、単語と参考例を同じ更新データから生成する。

公開CSVなら配信用タブだけを公開する。非公開Sheetならサーバーに閲覧権限だけを与え、必要列を配信する。シートが非公開でも、アプリに配信・表示した教材内容は利用者が取得できる。
